# ATM Management System

A web-based ATM Management System developed using Python Flask, HTML, CSS, and MySQL. The application provides basic ATM operations through a simple and user-friendly interface.

## 🚀 Features

- User Registration
- User Login
- Secure Logout
- ATM Dashboard
- Check Account Balance
- Deposit Money
- Withdraw Money
- Transfer Money
- Transaction History
- Responsive Web Interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- MySQL
- Jinja2
